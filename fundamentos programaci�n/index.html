Conceptos centrales

Qué es un algoritmo

Definición

Un algoritmo es un conjunto finito y preciso de instrucciones para resolver un problema. Sus elementos son: entrada, proceso, salida, eficiencia (tiempo/espacio) y corrección.

Representación

  • Pseudocódigo: lenguaje natural mezclado con estructuras de programación.
  • Diagrama de flujo: símbolos gráficos (óvalo=inicio/fin, paralelogramo=entrada/salida, rectángulo=proceso, diamante=decisión).

Estructuras lógicas

EstructuraDescripción
SecuenciaInstrucciones ejecutadas una tras otra en orden.
SelecciónDecisiones basadas en condiciones (if/else, switch).
IteraciónRepetición de bloques de código (for, while, do-while).

Estructuras de decisión

if/else y switch-case

Branching basado en condiciones booleanas.

```csharp if (condicion) { // bloque si es verdadero } else if (otraCondicion) { // bloque alternativo } else { // bloque por defecto } ```

switch-case

```csharp switch (expresion) { case valor1: // bloque 1; break; case valor2: // bloque 2; break; default: // bloque por defecto; break; } ```

Ejemplos de aplicación: verificar si un número es primo, determinar año bisiesto (divisible por 4, no por 100 a menos que también por 400), clasificar notas (A–F) y calcular descuentos en una tienda de ropa.

Estructuras de repetición

Ciclos for, while y do-while

Repetición de bloques de código.

CicloUso típicoSintaxis clave
forNúmero conocido de iteracionesfor (init; cond; incr)
whileNúmero desconocido, condición primerowhile (cond)
do-whileAl menos una ejecucióndo { } while (cond);
```csharp // for: imprimir 1 a 10 for (int i = 1; i <= 10; i++) { Console.WriteLine(i); } // while: suma hasta negativo int suma = 0; while (true) { int n = int.Parse(Console.ReadLine()); if (n < 0) break; suma += n; } ```

Colecciones de datos

Arreglos, diccionarios y listas

Almacenamiento de múltiples valores del mismo tipo.

Arreglo unidimensional

```csharp int[] numeros = new int[5]; numeros[0] = 10; foreach (int n in numeros) { ... } Array.Sort(numeros); ```

Arreglo bidimensional (matriz)

```csharp int[,] matriz = new int[filas, columnas]; matriz[fila, columna] = valor; // Ejemplo: tabla de multiplicar 10×10 tabla[i, j] = (i + 1) * (j + 1); ```

Diccionario

```csharp Dictionary notas = new Dictionary(); notas.Add("Juan", 85); if (notas.ContainsKey("Juan")) { ... } foreach (var kvp in notas) { kvp.Key; kvp.Value; } ```

Lista dinámica

```csharp List nombres = new List(); nombres.Add("Ana"); if (nombres.Contains("Ana")) { ... } ```
