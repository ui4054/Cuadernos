Orientación

¿Qué encontrarás aquí?

El curso enseña a construir aplicaciones web que consumen y exponen APIs. Conceptos centrales

HTML, CSS y JavaScript del cliente

HTML: estructura semántica

HTML no es un lenguaje de programación, es un lenguaje de marcado que da estructura al contenido. Elementos clave: <html>, <head>, <body>, <h1>–<h6>, <p>, <ul>/<ol>, <a>, <img>.

CSS: presentación y caja

CSS separa el contenido de la presentación. Sintaxis: selector { propiedad: valor; }. El modelo de caja (box model) define contenido, relleno (padding), borde (border) y margen (margin) de cada elemento.

JavaScript: interactividad y fetch

JavaScript manipula el DOM, reacciona a eventos y hace peticiones de red a APIs. La función fetch(url, opciones) devuelve una promesa que se resuelve con un objeto Response:

```javascript async function getReservaciones() { const res = await fetch(API_URL); if (!res.ok) throw new Error("Error al obtener reservaciones"); return res.json(); } ```

JavaScript y datos

Estructuras de datos y JSON

Arrays, objetos, diccionarios y serialización JSON.

Arrays

Lista ordenada de elementos. Métodos principales:

```javascript let numeros = [1, 2, 3]; numeros.push(4); // [1,2,3,4] - agregar al final numeros.pop(); // [1,2,3] - eliminar el último numeros.unshift(0); // [0,1,2,3] - agregar al inicio numeros.shift(); // [1,2,3] - eliminar el primero ```

Métodos de transformación y acumulación:

```javascript let dobles = edades.map(x => x * 2); // transformar let mayores = edades.filter(x => x >= 18); // filtrar let suma = edades.reduce((acc, val) => acc + val, 0); // acumular ```

Objetos literales y diccionarios

Colección de propiedades clave: valor. Acceso con notación de punto o corchetes:

```javascript let persona = { nombre: "Ana", edad: 28, ciudad: "Bogotá" }; console.log(persona.nombre); // "Ana" persona.profesion = "Ingeniera"; // agregar propiedad ```

JSON

Formato de texto para intercambio de datos. Conversión entre objeto JavaScript y texto JSON:

```javascript let jsonStr = JSON.stringify(usuario); // objeto → texto JSON let objeto = JSON.parse(jsonStr); // texto JSON → objeto ```

API REST y backend

Express, Mongoose y MongoDB

Construcción de un backend REST para gestionar reservaciones.

Servidor Express

Express es un framework para construir APIs en Node.js. Configuración básica:

```javascript const express = require('express'); const cors = require('cors'); const mongoose = require('mongoose'); const app = express(); app.use(cors({ origin: '*' })); app.use(express.json()); const PORT = 5000; app.listen(PORT, () => console.log('Servidor en el puerto', PORT)); ```

Endpoints REST de reservaciones

MétodoRutaDescripción
GET/api/reservacionesListar todas las reservaciones
POST/api/reservacionesCrear una nueva reservación
GET/api/reservaciones/:idObtener una reservación por ID
PUT/api/reservaciones/:idActualizar una reservación existente
DELETE/api/reservaciones/:idEliminar una reservación por ID

Modelo de datos con Mongoose

```javascript const ReservacionSchema = mongoose.Schema({ nombre: { type: String, required: true }, apellido: { type: String, required: true }, telefono: { type: String, required: true }, habitacion: { type: String, required: true }, fecha_entrada: { type: Date, required: true }, fecha_salida: { type: Date, required: true }, precio: { type: Number, required: true, default: 0 }, }, { timestamps: true }); const Reservacion = mongoose.model("Reservacion", ReservacionSchema); ```

Frontend con fetch

Consumo de API desde el navegador

Cómo el frontend se comunica con el backend usando fetch().

Funciones de API con fetch

```javascript const API_URL = "http://localhost:4001/api/reservaciones"; async function createReservacion(data) { const res = await fetch(API_URL, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(data) }); if (!res.ok) throw new Error("Error al crear reservación"); return res.json(); } async function deleteReservacion(id) { const res = await fetch(`${API_URL}/${id}`, { method: "DELETE" }); if (!res.ok) throw new Error("Error al eliminar reservación"); } ```

Renderizado dinámico de tabla

Cada reservación se convierte en una fila <tr> insertada en el <tbody> de la tabla:

```javascript function renderFila(reservacion) { const fila = document.createElement("tr"); fila.innerHTML = ` ${reservacion.nombre} ${reservacion.apellido} $${reservacion.precio} `; return fila; } ```

Prototipo full stack

Backend y frontend separados

Arquitectura con backend en el puerto 4001 y frontend servido como archivos estáticos en el puerto 3000.

Estructura de carpetas

``` project-root/ ├── models/ │ └── reservacion.models.js ├── server.js # API Express en puerto 4001 ├── index.js # Frontend Express en puerto 3000 (express.static) ├── package.json └── public/ ├── index.html ├── styles.css └── script.js ```

Servidor de archivos estáticos

El frontend se sirve con express.static('public'), permitiendo acceder al HTML, CSS y JS del cliente desde el navegador:

```javascript const express = require('express'); const app = express(); app.use(express.static('public')); app.listen(3000, () => console.log('Servidor en el puerto 3000')); ```

Conexión a MongoDB Atlas

El backend se conecta a una base de datos en la nube mediante una cadena de conexión:

```javascript mongoose.connect("mongodb+srv://USUARIO:CLAVE@cluster.mongodb.net/?retryWrites=true&w=majority&appName=app") .then(() => { console.log("Connected to database"); app.listen(4001, () => console.log('Servidor en el puerto 4001')); }) .catch((error) => { console.log("Connection Failed"); console.log({ message: error.message }); }); ```
