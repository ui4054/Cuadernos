Conceptos centrales

HTML, CSS y JavaScript

Estructura de un documento HTML5

Un documento HTML básico consta de declaración <!DOCTYPE html>, elemento raíz <html>, <head> (metadatos) y <body> (contenido visible):

```html Título de la página

Encabezado principal

Párrafo de contenido.

```

CSS: hojas de estilo en cascada

CSS separa la presentación de la estructura. Un ejemplo de regla:

```css section { margin: 20px auto; padding: 20px; max-width: 800px; background: #fff; border-radius: 8px; } ```

Flexbox permite disponer elementos en una dirección (fila o columna) con control de alineación, espaciado y envoltura:

```css .flex-container { display: flex; justify-content: space-around; align-items: center; flex-wrap: wrap; gap: 20px; } ```

JavaScript: interactividad en el navegador

Se utiliza para validar formularios antes del envío y manipular el DOM. Ejemplo de escucha de evento submit:

```javascript document.getElementById('formulario').addEventListener('submit', function (e) { if (!validar()) { e.preventDefault(); } }); ```

El desplazamiento suave se logra con window.scrollTop({ behavior: 'smooth' }).

CRUD y base de datos

Persistencia con PHP y MySQL

Operaciones de crear, leer, actualizar y eliminar registros en una tabla de reservaciones.

Conexión a MySQL

El archivo db.php establece la conexión y se incluye en los scripts que la necesitan:

```php $host = 'localhost'; $user = 'root'; $password = ''; $database = 'hotel_reservas'; $conn = mysqli_connect($host, $user, $password, $database); if (!$conn) { die("Error de conexión: " . mysqli_connect_error()); } ```

Operaciones CRUD

OperaciónArchivoSentencia SQL
Crearcreate.phpINSERT INTO reservaciones (...) VALUES (...)
Leerread.phpSELECT * FROM reservaciones
Actualizarupdate.phpUPDATE reservaciones SET ... WHERE id = ?
Eliminardelete.phpDELETE FROM reservaciones WHERE id = ?

Estructura de la tabla

```sql CREATE TABLE reservaciones ( id INT AUTO_INCREMENT PRIMARY KEY, nombre VARCHAR(50) NOT NULL, apellido VARCHAR(50) NOT NULL, telefono VARCHAR(20) NOT NULL, habitacion VARCHAR(10) NOT NULL, fecha_entrada DATE NOT NULL, fecha_salida DATE NOT NULL, precio DECIMAL(10, 2) NOT NULL ); ```
