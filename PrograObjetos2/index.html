Conceptos centrales

Herencia: clases base y derivadas

Definición

La herencia permite que una clase (subclase o clase derivada) herede atributos y métodos de otra clase (superclase o clase base). La subclase accede a las funcionalidades de la superclase y puede añadir o sobrescribir funcionalidades propias.

Beneficios

  • Reutilización de código: se evita duplicar atributos y métodos.
  • Mantenimiento: cambios en la superclase se propagan a todas las subclases.
  • Jerarquía de clases: relaciones que representan conceptos del mundo real.

Ejemplo: Persona → Empleado

```csharp // Clase base public class Persona { public string Nombre { get; set; } public int Edad { get; set; } public void Saludar() { Console.WriteLine($"Hola, mi nombre es {Nombre} y tengo {Edad} años."); } } // Subclase public class Empleado : Persona { public string Puesto { get; set; } public void Trabajar() { Console.WriteLine($"{Nombre} está trabajando como {Puesto}."); } } ```

Uso:

```csharp Empleado empleado = new Empleado(); empleado.Nombre = "Carlos"; empleado.Edad = 30; empleado.Puesto = "Desarrollador"; empleado.Saludar(); // método heredado de Persona empleado.Trabajar(); // método propio de Empleado ```

Ejemplo: Juego de rol

Jerarquía: Personaje → Mago, Guerrero, Bardo, Enano (→ Guerrero), Elfo. Cada subclase añade atributos y métodos específicos (PuntosDeMagia, Fuerza, Instrumento, Resistencia, Agilidad).

Interfaces

Contratos de comportamiento

Una interfaz define un conjunto de miembros que las clases implementadoras deben proporcionar.

```csharp public interface IActualizable { void ActualizarDatos(string nombre, string apellido, string telefono); } ```

Implementación en el modelo:

```csharp public class ModeloPersona : IActualizable { public string Nombre { get; private set; } public string Apellido { get; private set; } public string Telefono { get; private set; } public void ActualizarDatos(string nombre, string apellido, string telefono) { Nombre = nombre; Apellido = apellido; Telefono = telefono; } } ```

Una interfaz permite que clases no relacionadas (ModeloPersona y VistaPersona) implementen el mismo contrato, habilitando polimorfismo y desacoplamiento.

Patrón MVC

Modelo-Vista-Controlador

Separación de responsabilidades en tres componentes.

ComponenteResponsabilidadClase ejemplo
ModeloGestiona los datos y la lógica de negocio.ModeloPersona
VistaPresenta los datos al usuario.VistaPersona
ControladorIntermediario entre modelo y vista; procesa entradas del usuario.ControladorPersona
```csharp public class ControladorPersona { private ModeloPersona _modelo; private VistaPersona _vista; public ControladorPersona(Persona modelo, VistaPersona vista) { _modelo = modelo; _vista = vista; } public void CambiarDatos(string nombre, string apellido, string telefono) { _modelo.ActualizarDatos(nombre, apellido, telefono); _vista.ActualizarDatos(nombre, apellido, telefono); } } ```

Flujo: Usuario → Controlador.CambiarDatos() → Modelo.ActualizarDatos() y Vista.ActualizarDatos().
