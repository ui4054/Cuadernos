Conceptos centrales

De variables a estructuras de datos

Tipos de datos y variables

En Python, una variable es una referencia a un objeto en memoria. Los tipos básicos son:

TipoDescripciónEjemplo
intEnteros (precisión ilimitada)42, -7
floatPunto flotante (IEEE 754)3.14, -2.5e10
strSecuencia inmutable de caracteres Unicode"hola", 'mundo'
boolValores lógicos True/False5 > 3 → True

La asignación x = 10 vincula el nombre x al objeto entero 10. Reasignar x = "diez" hace que x referencie un objeto str distinto; Python es de tipado dinámico.

Operadores aritméticos

Los operadores siguen la precedencia matemática estándar (potencia antes que multiplicación/división antes que suma/resta). Destacan dos operadores de división:

\[ \begin{aligned} \text{División real:} &\quad 10 / 3 = 3.333\ldots \\ \text{División entera:} &\quad 10 // 3 = 3 \\ \text{Módulo (residuo):} &\quad 10 \% 3 = 1 \end{aligned} \]

La identidad a == (a // b) * b + (a % b) siempre se cumple para enteros.

Estructuras de control

Condicionales: if, elif, else evalúan expresiones booleanas. En Python, valores "falsy" incluyen 0, "", [], {}, None, False.

Bucles:

  • for x in iterable: itera sobre cualquier iterable (lista, range, tupla, diccionario, conjunto).
  • while condicion: repite mientras la condición sea verdadera; requiere actualizar la variable de control dentro del cuerpo.

Ambos admiten break (salida inmediata) y continue (saltar a la siguiente iteración).

Listas y tuplas

Listas ([]): mutables, ordenadas, admiten duplicados. Operaciones típicas: append, remove, pop, insert, indexación y rebanado (lista[1:4]).

Tuplas (()): inmutables, ordenadas. Útiles para registros fijos o claves de diccionario. Desempaquetado: a, b, c = (1, 2, 3).

Diccionarios

Colección de pares clave: valor con claves únicas e inmutables (str, int, tuple). Acceso en O(1) promedio: d["clave"] (lanza KeyError si no existe) o d.get("clave", default). Métodos: keys(), values(), items(), del d["clave"].

Ejemplos guiados

Código comentado paso a paso

Estos fragmentos retoman los ejercicios propuestos en el cuaderno con explicación detallada.

Ejemplo 1: Calculadora básica con entrada de usuario

```python # Solicitar dos números enteros num1 = int(input("Ingresa el primer número: ")) num2 = int(input("Ingresa el segundo número: ")) # Operaciones aritméticas print("Suma:", num1 + num2) print("Resta:", num1 - num2) print("Multiplicación:", num1 * num2) print("División:", num1 / num2) # resultado float print("División entera:", num1 // num2) # cociente entero print("Residuo:", num1 % num2) print("Potencia:", num1 ** num2) ```

Puntos clave: input() devuelve str; int() convierte a entero. La división / siempre produce float en Python 3.

Ejemplo 2: Números pares del 1 al 100 (bucle for)

```python # range(inicio, fin_excluido, paso) for i in range(2, 101, 2): # 2, 4, 6, ..., 100 print(i) ```

Alternativa con while:

```python i = 2 while i <= 100: print(i) i += 2 ```

Ejemplo 3: Reporte de estudiante con diccionario

```python estudiante = { "nombre": "Carlos", "edad": 21, "carrera": "Ingeniería" } # Agregar promedio estudiante["promedio"] = 9.5 # Mostrar reporte formateado print(f"Estudiante: {estudiante['nombre']}") print(f"Edad: {estudiante['edad']} años") print(f"Carrera: {estudiante['carrera']}") print(f"Promedio: {estudiante['promedio']}") ```

Las f-strings (f"...") permiten interpolar expresiones dentro de cadenas de forma legible y eficiente.

Ejemplo 4: Encontrar el máximo en una lista

```python numeros = [17, 3, 92, 5, 41] maximo = numeros[0] for n in numeros[1:]: if n > maximo: maximo = n print("El mayor es:", maximo) # Equivalente nativo: max(numeros) ```

Este patrón de "inicializar con el primer elemento y actualizar" es la base de muchos algoritmos de reducción.
